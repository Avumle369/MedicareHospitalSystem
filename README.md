This Java application is a console-based Hospital Patient Admission System designed to digitize patient records and bed management for a 20-bed hospital ward.Core
CapabilitiesPatient Records Management: Registers, searches, updates, and deletes patients across three categories—Inpatient, Outpatient, and Emergency.Interactive 
2D Bed Management: Models a $4 \times 5$ grid layout of 20 beds (B01 to B20), allowing automated bed allocation exclusively for Inpatients and freeing up beds upon 
discharge.Ward Reporting & Analytics: Displays current ward occupancy maps, counts available vs. occupied beds, calculates the occupancy percentage, and sorts patient 
records by name or ID.Validation & Security Rules: Prevents duplicate patient IDs, blocks double-allocating occupied beds, and prevents bed assignments when the ward
reaches 100% capacity.
